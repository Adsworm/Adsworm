| Fix | Who says it | Status |
|---|---|---|

**Recommend installing: ctc-forced-aligner.** It is the only CPU tool here that takes "audio + my word list" and handles both scripts without a transliteration step.
```bash
python3 -m venv ~/.venvs/align && . ~/.venvs/align/bin/activate          # optional: keeps PyTorch out of the render environment
pip install torch torchcodec --index-url https://download.pytorch.org/whl/cpu   # CPU builds; torch 2.15.0+cpu for Python 3.13 is listed
pip install git+https://github.com/MahmoudAshraf97/ctc-forced-aligner.git       # needs g++ and ffmpeg (both present)
```
```python
import torch
from ctc_forced_aligner import (load_alignment_model, load_audio, generate_emissions,
                                preprocess_text, get_alignments, get_spans, postprocess_results)
words = ["October", "में", "मेरे", "ads", "ने", "सिर्फ", "पैसा", "जलाया"]        # spoken order; numbers spelled out
model, tokenizer = load_alignment_model("cpu", dtype=torch.float32)              # first run downloads 1.26 GB
audio = load_audio("voice.wav", model.dtype, model.device)                       # ffmpeg → 16 kHz mono
emissions, stride = generate_emissions(model, audio, batch_size=4)
tokens, text = preprocess_text(" ".join(words), romanize=True, language="hin")   # uroman: both scripts → a–z
segments, scores, blank = get_alignments(emissions, tokens, tokenizer)
out = postprocess_results(text, get_spans(tokens, segments, blank), stride, scores)
assert len(out) == len(words)                                                    # one {"start","end","text","score"} per word
timings = [(w, o["start"], o["end"], o["score"]) for w, o in zip(words, out)]    # low score = check that word by ear
```
Keep three forms per word at the same index: voice text (Devanagari/Latin), caption text (Latin Hinglish), timing. Then captions cannot drift from speech.
**Licence warning:** the default model is non-commercial. For client work: (a) take timings from the voice engine, (b) use the ElevenLabs alignment API, or (c) pass `model_path=` a permissive Hindi model and all-Devanagari words (`ai4bharat/indicwav2vec-hindi` Apache-2.0, gated; `Harveenchadha/vakyansh-wav2vec2-hindi-him-4200` MIT; licence tags read on Hugging Face, **not tested with this tool**).

## D. Keeping a Hinglish explainer understandable (checkable rules)
The "Rule" column is what the source says; the "Check" column is my way of testing it and is not from the source.
| # | Rule | Check | Status · source |
|---|---|---|---|
| 1 | Short, direct sentences; one point each: "वाक्य छोटे सीधे और स्पष्ट लिखे जाएँ।" · "एक ही वाक्य में कई बात कहने के लोभ से बचना चाहिए।" | One claim per sentence; no "और" joining two claims | VERIFIED · NCERT-based Class 12 "विभिन्न माध्यमों के लिए लेखन": https://www.learninsta.com/cbse-class-12-hindi-elective-rachana-vibhinn-maadhyamon-ke-lie-lekhan/ |

## What I would do
1. **Voice:** leave Higgsfield presets for Hinglish. Test **Sarvam Bulbul** first (`shubh_enhi_ads` and `ritu_hi_reels` on v4-flash; `shubh` / `ishita` on v3): it is the only vendor whose docs define Hinglish voices and the script rule. Owner provides a Sarvam API key and buys credits before publishing (free-credit output may be non-commercial).
2. **A/B on the same two lines:** ElevenLabs direct API, v4, a Hindi library voice (Bunty, Monika Sogam), `language_code: "hi"`, `with-timestamps`. Needs an ElevenLabs key on Starter or above. A native speaker picks by ear; I could not listen.
3. **Script format for the voice:** Hindi in Devanagari, English words in Latin, never romanised Hindi. Captions stay Latin Hinglish, generated from the same word list.
4. **Timing:** if ElevenLabs wins, use its character timings and install nothing. If Sarvam wins, install **ctc-forced-aligner** (commands in B), and settle the model licence before client delivery.
5. **edge-tts:** drafts only, never in a published reel.
6. **Skills:** add `sarvam-mcp` if Sarvam is chosen; show the owner `motion-team/creative-strategy-skills` for hooks; treat the rest as reading material.
7. **Understanding check:** write rules D1–D7 into our own script check (word list, numbers, pace, gloss at first use). No existing skill does this for Hinglish.
