# Reference reel teardown — instagram.com/reel/Det2rTBzoEq (55 s, Hinglish, @techstackbro)

Topic: "this whole channel is made with AI — I only decide. Let me show you how." Same kind of pipeline as ours (Claude Code script → OpenAI voice, 5 takes → Whisper word timings → coded avatar → Remotion → parallel agents).

## Why it holds attention (what to copy as principles, not the look)
1. **Hook = bold claim + promise, in 3 s.** "Ye poora channel AI se banta hai. Main bas decide karta hoon. Dikhata hoon kaise." The visual proves it instantly: a wall of the channel's reels multiplies from 4 → 20 tiles in ~1 s, then a tilted sticker slaps on: "100% AI-made… almost" (a joke = personality).
2. **One teacher, talking to you.** No second character. First person, casual, short phrases. ~3.5 words/s — fast but every phrase is 2–5 words.
3. **The mouth moves with the voice** (loudness → mouth open/half/closed). The character feels alive even as a flat drawing. He even shows this on screen.
4. **Karaoke captions in a small speech bubble next to the head**: only 2–4 words at a time, the current word in a purple pill, upcoming words grey. Nothing to "read" — you hear and see the same word.
5. **The top half is a live "proof board" that builds every 1–2 s**: terminal typing the topic, script appearing line by line with the current line highlighted, a "sources ✓" badge, waveform, 5 takes with ✕/✓, JSON with the active word highlighted, code with the active line highlighted. Every claim is shown, not told.
6. **Section pills** ("step 1 · script ✍️", "step 2 · awaaz 🎙", …) — the viewer always knows where they are; numbered steps = open loop ("there are 5").
7. **Stickers as punctuation**: tilted, coloured, pop-in with overshoot — "approve ✓", "sync", "parallel ⚡", "drawing ✕ code ✓". Each one is a mini payoff.
8. **"Sabse mazedaar" re-hook near the end** (best part saved for last) → agents in parallel → "kitna time? ~6 min → ~15 min" with a timer.
9. **Ending stack**: "ye pipeline chahiye? 👀" → "comment: pipeline" sticker → "poora breakdown agle reels mein" (series promise, with the 5 step icons) → avatar zooms to centre, big: "ye reel us dost ko bhejo jo sochta hai reels banana bahut mehnat hai" (share prompt) → a Follow button flips to "Following ✓" → wink.
10. **Style**: light grey dot-grid paper, black 2–3 px outlines, small offset shadows (neo-brutalist), rounded UI windows with traffic-light dots, a handwriting font for annotations, 3 accent colours (orange, purple, pink).
